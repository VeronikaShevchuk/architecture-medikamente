## Процесс 1: Запись пациента
|AS-IS (проблема)|	TO-BE (улучшение)|	Ожидаемый эффект|
|---|---|---|
|Ручной ввод в Excel|	Онлайн-портал с интеграцией в БД|	Снижение ошибок на 90%|
|Нет проверки свободных слотов|	API с реальным временем + кэш Redis|	Исключение двойных записей|
|Нет напоминаний|	Автоматические SMS/Email/Push за 1 день|	Снижение неявок на 40%|
|Ресепшен видит всех пациентов|	RBAC: только свои записи, без диагнозов|	Соответствие 152-ФЗ|
|Нет аудита|	Логирование каждой записи в ELK|	Возможность расследования|
