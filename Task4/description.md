|---|---|---|---|---|
|Инфраструктура|	Старый сервер не выдержит нагрузку|	Простой системы	|Развернуть новый K8s кластер параллельно|High|
||Сетевые лимиты (1 GbE)|	Медленная миграция данных|	Использовать 10 GbE или миграцию по частям|	Medium|
||Нет резервного канала|	Полная остановка при сбое|	Внедрить резервный интернет-канал|	High|
|ПО|	1С в файловом режиме|	Блокировки, медленная работа|	Перевести 1С в клиент-сервер до миграции|	High|
||Excel не конвертируются в БД	|Потеря/искажение данных|	Разработать ETL-скрипты с валидацией|	High|
||Нет API для лаборатории|	Ручная работа|	Разработать API Gateway + адаптер|	Medium|
|Данные|	10 000+ строк из Excel|	Длительная миграция	|Мигрировать поэтапно (по 1000 записей)	|High|
||Дублирование (Excel+1С)|	Рассогласование|	Выбрать источник истины (1С)|	High|
||Неструктурированные сканы|	Невозможно индексировать|	OCR + тегирование при загрузке	|Medium|
|Персонал|	Сотрудники не обучены|	Ошибки, отказ от работы|	Провести обучение за 2 недели до запуска|	High|
||Сопротивление изменениям|	Саботаж|	Назначить champion'ов из каждого отдела|	Medium|
||Нехватка DevOps/Java|	Задержка разработки	|Нанять 2 специалистов или аутсорс	|High|
|Процессы|	Нет плана миграции|	Хаос, простои|	Составить детальный план с вехами|	High|
||Нет отката|	Невозможность восстановиться|	Реализовать blue-green deployment|	High|
||Параллельная работа|	Двойной ввод, ошибки|	Интеграционный слой на 1 месяц|	Medium|
|Безопасность|	Данные мигрируют без шифрования|	Утечка ПД|	Использовать TLS + шифрование бэкапов|	Critical|
||Нет контроля доступа	|НСД в процессе|	Внедрить RBAC на время миграции	|High|
||Утечка при отладке|	Логи содержат ПД|	Маскировать ПД в логах	|High|

## Целевая архитектура (TO-BE)
|Компонент|	Целевое состояние	|Требования|
|---|---|---|
|Хранилище	|PostgreSQL кластер + MinIO	|High Availability, масштабирование|
|1С|Клиент-сервер|	До 100+ пользователей|
|Серверы|	K8s кластер (3+ нод)	|Отказоустойчивость|
|Бизнес-логика|	Микросервисы (Java, Spring)	|CI/CD, изолированность|
|Сеть|	VPN + TLS	|Защита передачи|
|Безопасность	|RBAC, ABAC, шифрование, аудит|	Соответствие 152-ФЗ|
